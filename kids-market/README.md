# 🎪 היריד

מרקטפלייס לילדים בני 8–13 למכירת צעצועים, ספרים ומשחקים, בפיקוח הורים מלא.

- **אפיון:** [docs/SPEC.md](docs/SPEC.md)
- **הקמה:** [docs/SETUP.md](docs/SETUP.md)

## מבנה

| תיקייה | מה יש בה |
|---|---|
| `supabase/migrations/` | הסכמה, הרשאות (RLS) וכל כללי העסקה בצד השרת |
| `supabase/tests/` | בדיקת זרימה מלאה מול Postgres |
| `src/lib/content.ts` | **כל הטקסטים** — אווטארים, קטגוריות, הודעות מוכנות, מדבקות. מנהלת המוצר עורכת כאן |
| `src/app/` | המסכים (Next.js App Router) |
| `src/app/api/upload` | העלאת תמונות: מחיקת GPS/EXIF והקטנה |
| `src/app/api/kid-login` | כניסת ילדים: קוד משפחה + PIN |

## עקרונות אבטחה

- כל שינוי מצב (אישור מודעה, הצעת מחיר, אישור עסקה, מסירה) עובר בפונקציית SQL שבודקת הרשאות. הממשק לא יכול לעקוף אותן.
- טקסט של ילדים מסונן בשרת: טלפונים, מיילים, קישורים, כתובות, רשתות חברתיות.
- תקרת מחיר 100 ₪ נאכפת במסד הנתונים.
- 5 ניסיונות PIN שגויים ← נעילה ל-15 דקות.
- התמונות פרטיות ומוגשות בקישורים חתומים לשעה.
